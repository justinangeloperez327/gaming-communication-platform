# Gaming Communication Platform

A Windows-first communication application for gaming communities and teams, focused on low-latency voice, screen sharing, game streaming, and minimal CPU, GPU, and memory overhead.

The desktop client uses **C++20 and Qt 6**. The application backend uses **Rust and Axum**. Real-time media will use **WebRTC through an established SFU**, with native Windows capture and hardware encoding integrated incrementally.

Source code and build instructions are being initialized. No voice, chat, or streaming functionality is implemented yet.
